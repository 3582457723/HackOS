# HackOS - Hacking Simulator Game

## 概要
HackOS は、リアルなハッキングシミュレーターゲームです。ターミナルベースの UI で、Linux コマンドと HackOS 専用の高度なハッキングコマンドを駆使して、ミッションをクリアしていくゲームです。

## 機能

### 🎮 基本機能
- **ブートアニメーション**: X-Server 風の本格的な起動シーン
- **ログイン/登録システム**: ユーザー管理、IP自動割り当て
- **マルチプレイヤー**: オンラインプレイヤーの検知・攻撃可能
- **ネットワークマップ**: スキャン結果の可視化
- **ターミナルシステム**: Linux 標準コマンド + HackOS 専用コマンド

### 💻 標準Linux コマンド
- **ファイル操作**: `ls`, `cd`, `pwd`, `cat`, `mkdir`, `touch`, `rm`, `cp`, `mv`
- **システム**: `whoami`, `hostname`, `uname`, `uptime`, `date`, `df`, `ps`
- **ネットワーク**: `ifconfig`, `ping`, `netstat`, `traceroute`

### 🔓 HackOS 専用コマンド
| コマンド | 説明 |
|---------|------|
| `connect <ip>` | 指定 IP のコンピュータに接続 |
| `scan` | ネットワークノードをスキャン |
| `porthack <port>` | ポート番号でハッキング |
| `sshcrack <ip>` | SSH ブルートフォース攻撃 |
| `replace [ファイル] "[old]" "[new]"` | ファイルのテキストを改ざん |
| `fileWipe [ファイル]` | ファイルを完全削除（復元不可） |
| `deepscan` | 隠しノード（バックドア）検知 |
| `logmirror` | 接続ログを改ざん |

### 🎯 ゲーム要素
- **ミッション**: 各種ハッキングタスクを受諾・完了
- **スキルツリー**: XP で新しいコマンドをアンロック
- **経験値(XP)**: ミッション完了で獲得
- **資金**: ハッキング成功で報酬獲得
- **レベルアップ**: XP に応じてレベル上昇

### 🎨 UI/UX
- **3パネルレイアウト**:
  - 左: メモリタスク/ノートパッド
  - 中央: メイン表示（ネットワークマップ、ミッション等）
  - 右: ターミナル
  - 下部: ブートローダー情報

- **ログ表示**: ログレベル（INFO, WARN, ERROR）に応じた色分け
- **ステータスバー**: 時刻、現在のIP、メモリ使用率、バッテリー表示

## インストール

### 必要な環境
- Node.js 18+
- npm または yarn

### セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/HackOS.git
cd HackOS

# 依存パッケージをインストール
npm install

# サーバーを起動
npm start

# 開発モード（ホットリロード有効）
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスしてください。

## 使用方法

### 初回起動
1. HackOS が起動します（ブートアニメーション表示）
2. 新規ユーザー登録または既存ユーザーでログイン
3. ユーザー名とパスワードを設定（IP は自動割り当て）
4. デスクトップが表示されます

### ターミナルでのコマンド実行
```bash
# ネットワークスキャン
scan

# 特定のサーバーに接続
connect 192.168.1.50

# ファイル一覧表示
ls

# ポートハッキング
porthack 80

# ファイル改ざん
replace secrets.txt "old_data" "new_data"

# ヘルプ表示
help
```

### ミッション完了
1. **MISSIONS** タブをクリック
2. ミッションを **ACCEPT** して開始
3. ターミナルでタスクを実行
4. 完了するとXPと資金を獲得

### スキルアンロック
1. **SKILL_TREE** タブをクリック
2. アンロック可能なスキルをクリック
3. 必要な XP を消費
4. 新しいコマンドが利用可能に

## セーブ機能

- **オートセーブ**: 30秒ごとに自動保存
- **手動セーブ**: SETTINGS タブから **SAVE GAME**
- **データ保存場所**: ブラウザの LocalStorage

## マルチプレイヤー機能

### オンラインノード検知
- `scan` コマンドで現在オンラインのプレイヤーを検知
- プレイヤーのIPアドレスがネットワークマップに表示
- クリックして接続・攻撃可能

### 防御システム
- 他のプレイヤーから攻撃を受けるとアラート
- ファイアウォールを強化して防御
- 逆探知で反撃可能（実装予定）

## トラブルシューティング

### サーバーが起動しない
```bash
# ポート 3000 が使用中の場合
PORT=3001 npm start
```

### LocalStorage がクリアされた
- ブラウザのキャッシュをクリアしていないか確認
- 設定タブから **LOAD GAME** で復元試行

### ネットワークマップが表示されない
- Canvas をサポートするブラウザを使用
- JavaScript コンソールでエラーを確認
